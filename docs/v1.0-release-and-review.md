# 《你小子给我飞起来》V1.0 上线与审核清单

> 代码版本：独立微信小游戏 `standalone/flying-chess-minigame`；**尚未真机验证联机上线**。
> 基础服务：微信云函数 `flyingRoom` + PostgreSQL 表 `public.flying_rooms`。
> 这是独立小游戏（`compileType: game`），不要误选普通小程序工程。

## V1.0 实际系统（供游戏内容审核选择）

1. **游戏玩法/规则设置系统**：单人红方与 3 AI；单人或真人好友共四方；每方四枚飞机；6 点起飞、6 点连投、同色跳 4、航线飞行、撞机回机场、终点反弹；设置项支持起飞条件、跳跃、航线、撞机、反弹及连续三次六点规则。规则设置在开局前完成。
2. **房间/好友联机系统**：最多 4 名玩家，可通过分享邀请或 32 位房间码加入；默认建房留 3 个真人空位；房主可调整 0–3 名 AI、难度；准备、开局、轮流掷骰、回合超时、重赛和重连。联机房间状态保存在 PostgreSQL，云端骰子与操作校验负责权威状态。
3. **货币系统（仅免费玩法积分）**：`幸运星`通过完整对局获取，每场 10 星，胜利额外 20 星；可兑换并启用 3 款本机纸张主题。没有充值、提现、转账、现金兑换、抽奖或付费商品；积分仅保存在本机，无法跨设备同步。不要向审核声称有钻石充值、会员或真实支付。
4. **战绩/个人成长系统**：本机显示完成场数、胜利次数、单机/联机场次、胜率、幸运星余额。记录为微信本地缓存，清空缓存或换设备可能丢失；不提供云端排行榜。
5. **新手说明系统**：独立规则页介绍起飞、跳跃、专属飞行、回合与胜利条件。仅以实际代码已实现功能为准。

### 审核可复制说明

**货币系统**：玩家完成一局飞行棋可获得10颗幸运星，若获得胜利额外奖励20颗。幸运星是通过游戏对局免费获得的本机虚拟积分，可在幸运星商店兑换纸张背景主题并切换使用。幸运星不支持充值、购买、提现、转让或现金兑换，清除本机缓存后相关数据可能丢失。

**战绩系统**：玩家进入“我的战绩”可查看本机已完成对局总数、胜利场次、单机及联机参与次数和胜率。数据只在本机保留，不参与跨用户排名，不要求额外登录。每场对局只计入一次，重赛可作为新对局单独记录。

**房间系统**：玩家创建好友房间后，可通过微信分享邀请其他玩家进入。一个房间最多容纳四个颜色座位，支持真人与电脑共同参与。房主可在开局前调整电脑人数和难度，真人完成准备后由房主开始，系统负责同步骰子、移动和回合状态。

> 如果微信平台系统下拉列表没有“战绩系统/房间系统”这种选项，优先选符合实际功能的标准系统分类，不要为了凑项错误选择付费商城、充值、钻石、VIP。

### 云函数

- 名称 `flyingRoom`，**Event 普通云函数**，Node.js 20.x，执行入口 `index.main`；
- 云端安装 `pg`、`wx-server-sdk`，不要将 `PGPASSWORD` 上传 GitHub；
- 使用 GitHub Actions **Package flyingRoom for SCF** 生成并验证标准 ZIP（根目录必须有 `index.js`）；
- 本版服务端新增 `room.round`（每局唯一计数），保存在已有 `state JSONB` 中，**不需要修改数据库表结构**；
- 如此前已部署旧代码，必须重新部署最新 `flyingRoom`，否则跨局战绩的回合计数无法正确区分。

### 重要上线阻塞项（不是代码内可直接修复）

微信开发者工具报：

```
cloud init error: Error: invalid scope 没有权限，请先开通云服务
```

代表微信侧云能力未授权或环境关联异常。检查：
- 项目使用真实**小游戏 AppID**（不能是源码中的 `touristappid` 占位）；
- 微信侧已开通云开发或可调用云函数的相应服务；
- 小游戏 AppID 已授权／关联环境 `gskj-d7gp86qo88751cc06`，并具有 `flyingRoom` 调用权限；
- 真机发起建房能出现在云函数日志中，且 PostgreSQL 有新增记录。

**仅云函数部署成功不代表联机已通过验收。**

## V1.0 已知限制

- 战绩、幸运星、主题是**本地功能**；卸载/清空缓存/更换设备可能丢失。
- 未实现充值、内购、VIP、全球排名或跨设备积分同步。
